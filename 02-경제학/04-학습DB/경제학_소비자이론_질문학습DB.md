## 1. 전체 구조

효용 → 무차별곡선 → MRS → 예산선/예산제약 → 소비자균형 → ICC/PCC·수요곡선 → 가격효과 → 대체효과+소득효과 → 보상수요·통상수요 → 정상재·열등재·기펜재 → 사회보장제도

## 2. 가격효과 핵심

**가격효과 = 대체효과 + 소득효과**

### 가격 하락
- 대체효과: 해당 재화 소비 증가(항상)
- 실질소득: 증가
- 정상재 소득효과: 소비 증가
- 열등재 소득효과: 소비 감소

### 최종 판정
- 정상재: + 대체 + + 소득 → 수요 증가
- 일반 열등재: + 대체 + - 소득, 대체효과가 더 커서 수요 증가
- 기펜재: + 대체 + - 소득, |소득효과|>|대체효과| → 수요 감소

**기펜재 = 열등재의 부분집합**

## 3. 보상수요 vs 통상수요

### 보상수요
- 대체효과만
- 소득효과 제거
- 항상 우하향

### 통상수요
- 대체효과 + 소득효과
- 실제 가격변화 후 수요
- 정상재: 우하향, 보상보다 완만
- 열등재: 우하향, 보상보다 가파름
- 기펜재: 우상향 가능

**통상 = 대체+소득 / 보상 = 대체만**

## 4. 특수관계

### 소득효과=0
가격효과=대체효과
→ **통상수요=보상수요**

### 가격효과=0
대체효과+소득효과=0
→ 두 효과가 정확히 상쇄
→ 가격 하락 시 대체효과는 +이므로 소득효과는 -
→ **반드시 열등재**

## 5. 그래프 판정

가격 하락 전 A → B → 최종점

- A→B = 대체효과
- B→최종점 = 소득효과
- A→최종점 = 가격효과

보상수요는 대체효과만 연결한 것이므로 우하향.
통상수요는 소득효과가 추가되어 재화 유형별로 기울기가 달라진다.

## 6. 문제풀이 알고리즘

가격 변화 확인
→ 대체효과 방향
→ 정상/열등 확인
→ 소득효과 방향
→ 두 효과의 크기 비교
→ 가격효과 결정
→ 통상수요 방향 판단
→ 소득효과 제거 여부 확인

숫자 예:
+3 + (-5) = -2 → 기펜재 가능.

## 7. 기존 소비자이론과 연결

### 소비자균형
MRS_XY = MU_X/MU_Y = P_X/P_Y

### Cobb-Douglas
U=X^αY^β
X=[α/(α+β)]M/P_X
Y=[β/(α+β)]M/P_Y
MRS=(α/β)(Y/X)

- 소득의 일정 비율을 각 재화에 지출
- 기본적으로 정상재
- 수요법칙 성립
- 무차별곡선 원점에 대해 볼록

### 완전대체재
직선 IC, 일정 MRS, 코너해 가능.

### 무차별곡선
일반적인 두 goods이면 우하향.
bad가 포함되면 우상향 가능.
무차별곡선은 서수적 선호를 표현.

### 밴드왜건 효과
타인의 소비가 자신의 수요에 영향을 주는 유행 추구 효과. 개별수요의 단순 수평합보다 시장수요가 커질 수 있다.

## 9. 핵심 함정

- 열등재 ≠ 기펜재
- 기펜재 ⊂ 열등재
- 보상수요 ≠ 대체재
- 보상수요는 항상 우하향
- 기펜재에서 우상향하는 것은 통상수요
- 가격효과 0 → 반드시 열등재
- 소득효과 0 → 통상수요와 보상수요 일치

## 10. ⭐ 암기 세트

⭐ 가격효과 = 대체효과 + 소득효과
⭐ 대체효과에는 수요법칙의 예외가 없다
⭐ 보상수요 = 대체만 = 항상 우하향
⭐ 통상수요 = 대체+소득
⭐ 기펜 = 열등재 + |소득효과|>|대체효과|
⭐ 소득효과 0 → 통상=보상
⭐ 가격효과 0 → 대체와 소득이 상쇄 → 열등재
