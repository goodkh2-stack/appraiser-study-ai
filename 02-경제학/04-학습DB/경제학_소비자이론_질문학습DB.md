## 1. 전체 구조

효용 → 무차별곡선 → MRS → 예산선/예산제약 → 소비자균형 → 완전대체재·완전보완재·Cobb-Douglas → ICC·엥겔곡선 → PCC·수요곡선 → 가격효과 → 대체효과+소득효과 → 보상수요·통상수요 → 정상재·열등재·기펜재 → 사회보장제도

---

# 2. 18강·19강 핵심: 가격효과

**가격효과 = 대체효과 + 소득효과**

X 가격이 하락하면:

### 대체효과
X가 상대적으로 싸짐 → Y 대신 X를 더 소비 → X 소비 증가.

### 소득효과
같은 명목소득으로 더 많은 재화를 살 수 있음 → 실질소득 증가.

대체효과에는 수요법칙의 예외가 없음.

⭐ 가격하락 → 대체효과는 해당 재화 소비 증가.

---

# 3. 정상재·열등재·기펜재

## 정상재
소득 증가 → 소비 증가.

가격 하락 시:
- 대체효과: +
- 소득효과: +
- 최종 가격효과: +

→ 수요량 증가.

## 열등재
소득 증가 → 소비 감소.

가격 하락 시:
- 대체효과: +
- 소득효과: -
- 일반 열등재에서는 대체효과가 더 커서 최종적으로 수요량 증가.

## 기펜재
열등재 중 소득효과의 절대적 크기가 대체효과보다 큰 경우.

가격 하락 시:
- 대체효과: +
- 소득효과: -
- |소득효과| > |대체효과|

→ 최종 수요량 감소
→ 수요법칙의 예외.

⭐ **기펜재 ⊂ 열등재**

예:
- 일반 열등재: +5 + (-2) = +3
- 기펜재: +3 + (-5) = -2

---

# 4. 보상수요곡선 vs 통상수요곡선

## 보상수요곡선
- 대체효과만 반영
- 소득효과 제거
- 항상 우하향

왜냐하면 대체효과에는 수요법칙의 예외가 없기 때문.

## 통상수요곡선
- 대체효과 + 소득효과
- 실제 가격변화에 따른 수요량 변화

### 재화별 관계

정상재:
- 우하향
- 보상수요보다 완만한 방향

열등재:
- 우하향
- 보상수요보다 가파른 방향

기펜재:
- 우상향 가능
- 보상수요는 여전히 우하향

⭐ **통상 = 대체+소득 / 보상 = 대체만**

⚠️ 보상수요의 '대체'는 대체재를 의미하지 않음.

---

# 5. 팔꿈치 그래프 직관

보상수요곡선에서 출발한다고 생각한다.

1. 보상수요: 우하향
2. 정상재: 소득효과가 같은 방향으로 추가 → 더 완만
3. 열등재: 소득효과가 반대 방향으로 작용 → 더 가파름
4. 기펜재: 소득효과가 대체효과보다 커짐 → 통상수요가 우상향

시험에서는 그래프를 복잡하게 직접 그리기보다 이 방향과 관계를 직관적으로 판정하는 것이 핵심.

---

# 6. Slutsky 그래프 읽기

가격 하락 전 A → 보상된 중간점 B → 최종점 C

- A→B = 대체효과
- B→C = 소득효과
- A→C = 가격효과

그래프를 정교하게 그리는 것보다 각 구간이 무엇을 의미하는지 읽는 능력이 중요.

---

# 7. 특수관계

## 소득효과 = 0

가격효과 = 대체효과

따라서:

**통상수요곡선 = 보상수요곡선**

## 가격효과 = 0

가격효과 = 대체효과 + 소득효과 = 0

→ 두 효과가 정확히 상쇄.

가격 하락 시 대체효과는 +이므로 소득효과는 -이어야 함.

→ 해당 재화는 반드시 열등재.

⭐
- 소득효과 0 → 통상 = 보상
- 가격효과 0 → 대체와 소득 상쇄 → 열등재

---

# 8. 문제풀이 알고리즘

가격 변화 확인
→ 대체효과 방향
→ 정상재/열등재 확인
→ 소득효과 방향
→ 두 효과의 절대크기 비교
→ 가격효과 결정
→ 통상수요 방향 판단
→ 보상수요인지 통상수요인지 확인

---

# 9. 기존 소비자이론 연결

## 소비자균형

MRS_XY = MU_X/MU_Y = P_X/P_Y

## Cobb-Douglas

U=X^αY^β

X=[α/(α+β)]·M/P_X

Y=[β/(α+β)]·M/P_Y

MRS=(α/β)(Y/X)

- 소득의 일정 비율을 각 재화에 지출
- 기본적으로 정상재
- 수요법칙 성립
- 무차별곡선은 원점에 대해 볼록

## 완전대체재

- 직선형 무차별곡선
- 일정한 MRS
- 코너해 가능

## 무차별곡선

일반적인 두 goods에서는 우하향.

bad가 포함되는 경우 우상향 가능.

무차별곡선은 서수적 선호를 표현하며 구체적인 만족량의 절대적 측정을 의미하지 않음.

## 밴드왜건 효과

타인의 소비가 자신의 수요에 영향을 미치는 유행 추구 효과.

---

# 10. 19강에서 사회보장제도 입문

소비자이론의 응용으로 사회보장제도가 시작됨.

## 현금보조
현금을 직접 지급.
→ 소비자가 사용처를 선택할 수 있음.

## 현물보조
특정 재화·서비스 또는 바우처 등을 제공.
→ 사용처가 제한될 수 있음.

## 가격보조
특정 재화를 구입할 때 가격을 낮춰줌.
→ 해당 재화를 구입하는 경우에 혜택이 발생.

19강에서는 개념을 소개하는 단계이며, 구체적인 그래프 분석은 다음 강의로 연결됨.

---

# 11. 19강 핵심 문제 판별

### 정상재의 통상수요곡선
보상수요보다 완만한 방향.

### 열등재의 보상수요곡선
우상향이 아님.
→ 보상수요는 항상 우하향.

### 기펜재
통상수요: 우상향 가능
보상수요: 우하향

---

# 12. 핵심 함정

- 열등재 ≠ 기펜재
- 기펜재 ⊂ 열등재
- 열등재 ≠ 나쁜 재화
- 보상수요 ≠ 대체재
- 보상수요는 항상 우하향
- 기펜재에서 우상향하는 것은 통상수요
- 소득효과 0 → 통상수요와 보상수요 일치
- 가격효과 0 → 반드시 열등재
- 무차별곡선이 항상 우하향한다고 단정하면 안 됨(bad 포함 시 우상향 가능)
- 무차별곡선은 기수적 효용의 절대값을 나타내는 것이 아니라 서수적 선호를 표현

---

# 13. ⭐ 암기 세트

⭐ 가격효과 = 대체효과 + 소득효과

⭐ 대체효과에는 수요법칙의 예외가 없다.

⭐ 보상수요 = 대체효과만 = 항상 우하향

⭐ 통상수요 = 대체효과 + 소득효과

⭐ 정상재: 대체 + 소득

⭐ 열등재: 대체 +, 소득 -

⭐ 기펜재: 열등재 + |소득효과|>|대체효과|

⭐ 기펜재는 열등재의 부분집합

⭐ 소득효과 0 → 통상수요 = 보상수요

⭐ 가격효과 0 → 대체효과와 소득효과 상쇄 → 열등재
