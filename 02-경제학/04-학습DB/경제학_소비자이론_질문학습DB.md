- 과목: 경제학
- 대단원: 소비자이론
- 학습 유형: 개념 질문 및 답변
- 기준일: 2026-09-27
- 학습시간: 이 메모에서는 확인하지 않음
- 정답률/이해도: 별도 확인 없음

## 핵심 개념 관계

### 소비자 선택의 기본 구조
효용 → 무차별곡선 → MRS → 예산제약 → 소비자균형

### 가격 변화의 구조
가격변화 → 가격효과 → 대체효과 + 소득효과 → 재화 유형별 결과 → 통상수요

### 수요곡선 구분
- 보상수요곡선: 대체효과만
- 통상수요곡선: 대체효과 + 소득효과

## 개념별 데이터

| 개념 | 핵심 내용 | 방향/관계 |
|---|---|---|
| MRS | 소비자가 원하는 주관적 교환비율 | MU_X/MU_Y |
| 무차별곡선 기울기 | MRS의 음수 | -MRS |
| 소비자균형 | 주관적 교환비율=시장 교환비율 | MRS=P_X/P_Y |
| 대체효과 | 상대가격 변화에 따른 소비조정 | 가격 하락 시 해당 재화 소비 증가 |
| 소득효과 | 실질소득 변화에 따른 소비조정 | 정상재/열등재에 따라 방향 다름 |
| 가격효과 | 두 효과의 합 | 대체효과+소득효과 |
| 보상수요 | 소득효과 제거 | 대체효과만 |
| 통상수요 | 실제 수요 | 대체효과+소득효과 |
| 기펜재 | 강한 음의 소득효과를 가진 열등재 | 가격 하락→수요량 감소 가능 |

## 질문-답변 핵심
- 보상수요곡선은 대체재가 아니다.
- 통상수요곡선은 일반적으로 말하는 보통의 수요곡선이다.
- 통상수요에서 음의 소득효과가 대체효과보다 크면 기펜재가 될 수 있다.
- 대체효과의 '대체'와 대체재의 '대체'는 구별한다.

## 취약/헷갈림 포인트
- 보상수요곡선과 대체재의 개념 혼동
- 통상수요와 보상수요의 효과 구성 혼동
- 기펜재의 조건에서 단순히 '열등재'라고만 기억하지 말고 효과의 상대적 크기까지 확인할 것

## 복습 필요 내용
- 보상수요곡선과 통상수요곡선을 그래프로 직접 비교
- 가격효과를 대체효과와 소득효과로 분해하는 문제 연습
- 정상재/열등재/기펜재를 가격 하락 및 가격 상승 각각의 방향으로 판단하는 연습
