# 경제학 질문답변 누적 정리 — 소비자이론

- 과목: 경제학
- 대단원: 소비자이론
- 목적: 2027년 감정평가사 1차 대비
- 기준: 이 채팅에서 실제로 공부하고 질문한 내용만 정리

## 1. 효용 → 무차별곡선 → MRS → 예산제약 → 소비자균형

### Q1. MRS(한계대체율)란?
- MRS는 한 재화를 1단위 더 얻기 위해 다른 재화를 얼마나 포기할 의사가 있는지를 나타낸다.
- 예: X를 1단위 더 얻기 위해 Y를 0.5단위 포기할 의사가 있다면 MRS_XY=0.5.
- 일반적인 경우
  MRS_XY = MU_X / MU_Y
- 무차별곡선의 기울기는 -MRS이다. MRS는 보통 절댓값으로 양수로 표현한다.
- 경제적 의미: 소비자가 느끼는 주관적 교환비율.

### Q2. 소비자균형은 왜 MRS = P_X/P_Y인가?
- MRS: 소비자가 생각하는 교환비율.
- P_X/P_Y: 시장이 강제하는 교환비율.
- 소비자균형에서는 소비자의 주관적 교환비율과 시장의 객관적 교환비율이 일치한다.
- 따라서
  MRS_XY = P_X/P_Y
- 예: P_X=2,000원, P_Y=4,000원이면 P_X/P_Y=1/2.
- X를 1단위 얻는 데 시장에서는 Y 1/2단위의 비용이 든다. 소비자의 MRS도 1/2이면 더 이상 소비조합을 바꿀 유인이 없다.

### Q3. 무차별곡선의 기본 의미는?
- 같은 효용을 주는 소비묶음들을 연결한 곡선.
- 일반적인 두 재화가 모두 재화(good)인 경우 우하향.
- 원점에서 더 멀리 있는 무차별곡선일수록 더 높은 효용을 나타낸다.
- 서로 다른 무차별곡선은 교차하지 않는다.
- 일반적인 경우 원점에 대해 볼록하며 MRS가 체감한다.
- 단, 특수한 선호에서는 형태가 달라질 수 있다.

### Q4. 완전대체재와 완전보완재는?
- 완전대체재: 한 재화를 다른 재화로 일정한 비율로 대체할 수 있다. 무차별곡선은 직선이며 MRS가 일정하다. 가격비율과 MRS의 관계에 따라 한 재화만 소비하는 코너해가 나타날 수 있다. 가격비율과 대체비율이 정확히 같으면 예산선 위 여러 점이 최적이 될 수 있다.
- 완전보완재: 두 재화를 일정한 비율로 함께 사용해야 한다. 무차별곡선은 L자형이고 꼭짓점이 핵심이다. 꼭짓점에서는 일반적으로 MRS가 정의되지 않는다.

### Q5. U=X^2+Y^2는 무엇을 의미하는가?
- U는 효용, X와 Y는 두 재화의 소비량.
- 대표적인 극단적 소비 선호 예시로 사용했다.
- 예: 총 10을 소비할 수 있을 때 (10,0)의 효용은 100, (5,5)의 효용은 50.
- 따라서 이 함수에서는 두 재화에 나누어 소비하는 것보다 한 재화에 집중하는 것을 선호한다.
- 일반화하면 U=A X^2+B Y^2이며 A,B는 각 재화의 선호 가중치 역할을 한다.
- 중요한 점: U=X^2+Y^2는 모든 극단적 소비 선호의 유일한 함수가 아니라 대표적인 예시이다.

### Q6. 예산제약은?
  P_X X + P_Y Y <= M
- P_X: X 가격
- P_Y: Y 가격
- X,Y: 소비량
- M: 소득
- 예산선은 P_X X + P_Y Y = M.
- 예산제약이 없다면 X^2+Y^2처럼 소비가 증가할수록 효용이 증가하는 함수에서는 유한한 최적소비가 존재하지 않을 수 있다.
- 예산선이 원점에서 멀어질수록 더 높은 효용수준에 도달할 수 있다.

## 2. 가격효과

### Q7. 가격효과의 구조는?
가격효과 = 대체효과 + 소득효과

가격이 하락하면:
1. 대체효과: 해당 재화가 상대적으로 싸져 소비가 증가하는 방향.
2. 소득효과: 실질소득이 증가한 효과. 정상재면 소비 증가, 열등재면 소비 감소.

### Q8. 정상재·열등재·기펜재는?
- 정상재: 소득 증가 → 소비 증가.
- 열등재: 소득 증가 → 소비 감소.
- 기펜재: 열등재 중에서 가격 변화에 따른 음(-)의 소득효과가 대체효과보다 절대값이 커져 수요법칙의 예외가 나타나는 경우.

가격 하락을 기준으로:
- 정상재: 대체효과(+) + 소득효과(+) → 수요량 증가.
- 열등재: 대체효과(+) + 소득효과(-) → 일반적으로 수요량 증가.
- 기펜재: 대체효과(+) + 소득효과(-)인데 |소득효과| > |대체효과| → 가격 하락에도 수요량 감소.

예:
대체효과 +3, 소득효과 -5
→ 가격효과 = +3-5 = -2
→ 가격이 하락했는데 소비량이 감소.

## 3. 보상수요곡선과 통상수요곡선

### Q9. 보상수요곡선이 대체재인가?
아니다.
- '대체재'는 콜라와 사이다처럼 서로 대신 소비할 수 있는 재화의 관계를 뜻한다.
- 보상수요곡선은 소득효과를 제거하고 대체효과만 나타낸 수요곡선이다.
- 따라서 '대체효과'의 대체와 '대체재'의 대체를 혼동하면 안 된다.

### Q10. 보상수요곡선이란?
- 가격 변화에 따른 소비 변화 중 소득효과를 제거하여 대체효과만 나타낸 수요곡선.
- 대체효과만 반영하므로 일반적인 설정에서 항상 우하향한다.
- 핵심: 보상수요 = 대체효과.

### Q11. 통상수요곡선이란?
- 통상수요곡선(ordinary demand curve)은 우리가 일반적으로 말하는 보통의 수요곡선이다.
- 대체효과 + 소득효과를 모두 반영한다.
- 즉, 실제 소비자가 가격 변화에 반응해 선택하는 수요를 나타낸다.
- 핵심: 통상수요 = 대체효과 + 소득효과.

### Q12. 통상수요에서 소득효과가 더 크면?
정확히는 열등재에서 소득효과의 절대값이 대체효과보다 큰 경우 기펜재가 된다.
- 대체효과는 가격 하락 시 + 방향.
- 열등재의 소득효과는 가격 하락 시 - 방향.
- |소득효과| > |대체효과|이면 가격효과가 -가 되어 가격 하락 → 수요량 감소.
- 따라서 통상수요곡선은 우상향할 수 있다.

## 4. 소비자이론 전체 구조

효용
→ 무차별곡선
→ MRS
→ 예산선/예산제약
→ 소비자균형

가격 변화가 발생하면
→ 가격효과
→ 대체효과 + 소득효과
→ 정상재 / 열등재 / 기펜재
→ 통상수요곡선과 보상수요곡선

## ⭐ 암기 포인트
- MRS = MU_X/MU_Y
- 무차별곡선 기울기 = -MRS
- 소비자균형: MRS = P_X/P_Y
- 가격효과 = 대체효과 + 소득효과
- 보상수요 = 대체효과만
- 통상수요 = 대체효과 + 소득효과
- 기펜재 = 열등재 + |소득효과| > |대체효과|
- 대체효과와 대체재는 다른 개념

## 🎯 시험 적용 사고방식
1. 가격이 변했는지 확인한다.
2. 해당 재화의 대체효과 방향을 먼저 판단한다.
3. 정상재인지 열등재인지 확인해 소득효과 방향을 판단한다.
4. 두 효과의 상대적 크기를 비교한다.
5. 총 가격효과의 방향을 결정한다.
6. 그 결과 통상수요곡선의 방향을 판단한다.
7. 소득효과를 제거한 상황이면 보상수요곡선을 생각한다.
