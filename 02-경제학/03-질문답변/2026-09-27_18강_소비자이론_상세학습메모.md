## 1. 18강의 위치

**효용 → 무차별곡선 → MRS → 예산선/예산제약 → 소비자균형 → ICC/PCC·수요곡선 → 가격효과 → 대체효과+소득효과 → 보상수요·통상수요 → 정상재·열등재·기펜재 → 사회보장제도**

18강은 특히 **가격효과를 그래프보다 직관으로 판정하는 능력**을 강화하는 강의다.

# 2. 가격효과의 핵심 구조

## 가격효과 = 대체효과 + 소득효과

X 가격이 하락하면 두 가지 일이 동시에 발생한다.

### ① 대체효과
X가 Y보다 상대적으로 싸진다.
→ Y 대신 X를 더 소비하려는 힘
→ **X 소비 증가**

대체효과는 상대가격 변화만 반영하므로 예외가 없다.

⭐ **대체효과에는 수요법칙의 예외가 없다.**

### ② 소득효과
같은 명목소득으로 더 많은 재화를 살 수 있다.
→ **실질소득(구매력) 증가**

예: 소득 100만원, X 가격 1만원이면 X 100개 가능. 가격이 5천원이 되면 X 200개까지 가능.

⭐ 가격 하락 → 실질소득 증가
⭐ 가격 상승 → 실질소득 감소

---

# 3. 정상재·열등재·기펜재

| 재화 | 소득 증가 시 소비 | 가격 하락 시 대체효과 | 가격 하락 시 소득효과 | 최종 결과 |
|---|---|---|---|---|
| 정상재 | 증가 | + | + | 수요 증가 |
| 열등재 | 감소 | + | - | 보통 수요 증가 |
| 기펜재 | 감소 | + | - | 수요 감소 가능 |

### 정상재
대체효과와 소득효과가 같은 방향.

### 열등재
두 효과가 반대 방향이지만 일반적으로 대체효과가 더 크다.

예: +5 + (-2) = +3
→ 가격 하락 → 수요 증가.

**열등재 ≠ 나쁜 재화 ≠ 기펜재**

### 기펜재
열등재 중에서

**|소득효과| > |대체효과|**

인 경우.

예: +3 + (-5) = -2
→ 가격 하락인데 수요 감소
→ 수요법칙의 예외.

⭐ **기펜재 = 열등재 + |소득효과| > |대체효과|**

---

# 4. 보상수요곡선과 통상수요곡선

## 보상수요곡선
소득효과를 제거하고 **대체효과만** 반영.

따라서 대체효과에는 수요법칙이 항상 성립하므로

⭐ **보상수요곡선은 항상 우하향**

## 통상수요곡선
실제 가격변화에 따른 소비량 변화로

**대체효과 + 소득효과**

를 모두 반영한다.

### 관계
- 정상재: 통상수요도 우하향, 보상수요보다 완만한 방향
- 열등재: 통상수요도 우하향하지만 보상수요보다 가파른 방향
- 기펜재: 통상수요는 우상향 가능, 보상수요는 여전히 우하향

⭐ **통상 = 대체 + 소득**
⭐ **보상 = 대체만**

⚠️ 보상수요의 '대체'는 **대체재**를 뜻하지 않는다. 보상수요는 수요곡선의 종류이고 대체재는 재화 간 관계다.

---

# 5. 18강의 '팔꿈치' 직관

복잡한 그래프를 처음부터 그리지 말고 다음처럼 읽는다.

**보상수요(대체효과만)**
→ 가격 하락으로 수요 증가
→ 여기까지가 기본 우하향

여기에 소득효과가 추가된다.

### 정상재
실질소득 증가 → 소비 추가 증가
→ 통상수요가 더 완만해진다.

### 열등재
실질소득 증가 → 소비 감소
→ 대체효과로 늘어난 부분을 일부 되돌린다.
→ 그래도 최초보다 수요가 많다면 통상수요는 우하향하지만 더 가파르다.

### 기펜재
소득효과가 더 크게 감소시킨다.
→ 최종 수요가 최초보다 감소
→ 통상수요가 우상향한다.

시험에서는 이 **보상수요 → 정상/열등/기펜 통상수요의 관계**를 읽는 것이 핵심이다.

---

# 6. Slutsky식 가격효과 그래프 읽기

가격 하락 전 최적점 = A

### A → B
동일한 효용수준에서 상대가격 변화만 반영
→ **대체효과**

### B → 최종점
가격 하락으로 실질소득이 증가한 효과
→ **소득효과**

### A → 최종점
두 효과를 합친 전체 변화
→ **가격효과**

즉

**A→B = 대체효과**
**B→최종점 = 소득효과**
**A→최종점 = 가격효과**

강의의 핵심은 세부 그래프를 암기하기보다 이 구조를 읽는 것이다.

---

# 7. 매우 중요한 특수관계 ① 소득효과 = 0

가격효과 = 대체효과 + 소득효과

소득효과가 0이면

**가격효과 = 대체효과**

보상수요는 대체효과만,
통상수요는 대체효과+소득효과를 반영하므로

⭐ **소득효과 = 0 → 통상수요곡선 = 보상수요곡선**

시험에서 직접 물을 수 있는 관계다.

---

# 8. 매우 중요한 특수관계 ② 가격효과 = 0

가격효과 = 대체효과 + 소득효과 = 0

가격이 하락하면 대체효과는 반드시 수요를 증가시킨다.

따라서 가격효과가 0이 되려면 소득효과가 정확히 반대로 작용해 완전히 상쇄해야 한다.

즉 가격 하락 기준:

**대체효과 + / 소득효과 - / 절대크기 동일**

소득효과가 음(-)이므로 해당 재화는 반드시 열등재다.

⭐ **가격효과 = 0 → 대체효과와 소득효과가 정확히 상쇄 → 반드시 열등재**

---

# 9. 문제풀이 알고리즘

가격 변화 문제를 보면 다음 순서로 판단한다.

① 가격이 상승했는가 하락했는가?
↓
② 대체효과 방향은?
↓
③ 정상재인가 열등재인가?
↓
④ 소득효과 방향은?
↓
⑤ 두 효과 중 어느 쪽이 더 큰가?
↓
⑥ 가격효과의 최종 방향은?
↓
⑦ 통상수요곡선의 방향은?
↓
⑧ 소득효과를 제거한 상황이면 보상수요곡선으로 판단

숫자가 주어지면 단순히 더한다.

예:
+4 + (-7) = -3
→ 가격 하락에도 수요량 감소
→ 기펜재 가능.

# 10. 18강 앞부분 복습: 완전대체재

완전대체재는 무차별곡선이 직선이고 MRS가 일정하다.

예산선과 무차별곡선의 기울기를 비교하여 최적점을 찾는다.

가격비율이 바뀌면 어느 한 재화만 소비하는 **코너해**가 바뀔 수 있다.

⭐ 완전대체재 → 직선 IC → 코너해 가능

---

# 11. Cobb-Douglas 복습

효용함수:

**U = X^αY^β**

효용극대화 수요:

**X = [α/(α+β)]·M/P_X**

**Y = [β/(α+β)]·M/P_Y**

α/(α+β)는 X에 지출하는 소득 비율,
β/(α+β)는 Y에 지출하는 소득 비율이다.

예:
α=1/3, β=2/3이면
- X 지출 = 소득의 1/3
- Y 지출 = 소득의 2/3

가격이 동일하면 Y를 X보다 많이 소비한다.

또한

**MRS_XY = (α/β)(Y/X)**

이므로 X가 증가할수록 Y/X가 감소하고 MRS가 감소한다.
→ 무차별곡선은 원점에 대해 볼록.

---

# 12. 무차별곡선 관련 복습

## 서수적 효용
무차별곡선은 효용의 절대적 숫자를 측정하는 것이 아니라 **선호의 순서**를 나타낸다.

⭐ 무차별곡선 → 서수적 효용

## 기울기
일반적인 두 재화가 모두 goods이면 우하향한다.

하지만 한 재화가 bad(비효용재)이면 우상향할 수 있다.

따라서 '무차별곡선은 항상 우하향'이라는 표현은 재화의 성격을 확인해야 한다.

---

# 13. 밴드왜건 효과 복습

밴드왜건 효과(악대차 효과)는
**다른 사람이 많이 소비하는 것을 나도 소비하고 싶어지는 현상**, 즉 유행을 추구하는 효과다.

개별 소비자가 타인의 소비를 고려하지 않고 결정한 개별수요의 수평합보다 시장수요가 더 커질 수 있다.

18강의 핵심 가격효과보다는 보조적인 문제 개념이다.

---

# 14. 다음 단원: 사회보장제도

18강 후반에서 소비자이론의 응용으로 사회보장제도에 들어갔다.

### 현금보조
정부가 돈을 직접 지급.
→ 소비자가 원하는 재화에 사용할 자유가 크다.

### 현물보조
특정 재화·서비스 또는 바우처를 제공.
→ 사용처가 제한될 수 있다.

### 가격보조
특정 재화를 구매할 때 가격을 낮춰준다.
→ 해당 재화를 구매하는 경우 혜택이 발생.

다음 단계에서는 세 제도의 **예산선 변화와 소비자 선택**을 그래프로 연결해야 한다.

# 16. 감평사 1차 시험 포인트

🎯 최우선:
1. 가격효과 = 대체효과 + 소득효과
2. 대체효과는 항상 수요법칙 성립
3. 보상수요는 항상 우하향
4. 정상재/열등재에 따른 소득효과 방향
5. 기펜재의 정확한 조건
6. 통상수요와 보상수요의 차이
7. 소득효과 0 → 통상수요 = 보상수요
8. 가격효과 0 → 대체효과와 소득효과 상쇄 → 열등재

⚠️ 함정:
- 열등재라고 기펜재인 것은 아니다.
- 기펜재는 열등재의 부분집합이다.
- 기펜재에서도 보상수요는 우하향한다.
- 보상수요와 대체재는 다른 개념이다.
- 가격효과 0은 정상재가 아니라 반드시 열등재.
- '열등재=나쁜 재화'로 이해하면 안 된다.

⭐ 암기:
**통상 = 대체 + 소득**
**보상 = 대체만**
**기펜 = 열등재 + |소득효과|>|대체효과|**
**소득효과 0 → 통상=보상**
**가격효과 0 → 대체와 소득이 상쇄 → 열등재**
