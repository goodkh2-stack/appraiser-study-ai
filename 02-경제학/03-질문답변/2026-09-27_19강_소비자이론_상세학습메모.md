# 경제학 19강 학습메모 — 소비자이론
## 2027 감정평가사 1차 합격용 / 복습용 상세 정리

- 과목: 경제학
- 대단원: 소비자이론
- 강의: 19강
- 학습일: 2026-09-27
- 학습시간/정답률/이해도: 확인되지 않음

## 1. 강의의 위치

효용 → 무차별곡선 → MRS → 예산선/예산제약 → 소비자균형 → 완전대체재·완전보완재·Cobb-Douglas → ICC·엥겔곡선 → PCC·수요곡선 → 가격효과 → 대체효과+소득효과 → 보상수요·통상수요 → 정상재·열등재·기펜재 → 사회보장제도

19강은 앞에서 배운 소비자이론을 문제로 복습하고, 가격효과와 수요곡선의 관계를 정리한 뒤 사회보장제도로 넘어가는 연결 강의다.

## 2. 복습한 핵심 개념

### 완전대체재
- 직선형 무차별곡선
- 일정한 MRS
- 코너해 가능
- 가격비율 변화에 따라 한 재화만 소비하는 최적선택이 나타날 수 있음

### Cobb-Douglas
U=X^αY^β

X=[α/(α+β)]·M/P_X
Y=[β/(α+β)]·M/P_Y
MRS=(α/β)(Y/X)

- 소득의 일정 비율을 각 재화에 지출
- 기본적으로 정상재
- 수요법칙 성립
- 무차별곡선 원점에 대해 볼록

### 무차별곡선
- 동일한 만족을 주는 소비조합을 연결
- 일반적인 두 goods에서는 우하향
- 원점에서 멀수록 높은 효용
- 서로 교차하지 않음
- 원점에 대해 볼록
- 서수적 선호를 표현
- bad가 포함되면 우상향 가능

### 밴드왜건 효과
타인의 소비가 자신의 수요에 영향을 미치는 유행 추구 효과.

## 3. 가격효과

가격효과 = 대체효과 + 소득효과

X 가격 하락:

### 대체효과
X가 상대적으로 싸짐 → X 소비 증가.
대체효과에는 수요법칙의 예외가 없음.

### 소득효과
가격이 하락하면 같은 명목소득으로 더 많이 살 수 있어 실질소득이 증가.

## 4. 정상재·열등재·기펜재

### 정상재
소득 증가 → 소비 증가.

가격하락:
대체효과 + / 소득효과 +
→ 수요량 증가.

### 열등재
소득 증가 → 소비 감소.

가격하락:
대체효과 + / 소득효과 -
일반 열등재에서는 대체효과가 더 커서 최종 수요량 증가.

### 기펜재
열등재 중 소득효과의 절대적 크기가 대체효과보다 큰 경우.

가격하락:
대체효과 + / 소득효과 -
|소득효과|>|대체효과|
→ 최종 수요량 감소
→ 수요법칙의 예외.

기펜재 ⊂ 열등재.

예:
+5 + (-2)=+3 → 일반 열등재
+3 + (-5)=-2 → 기펜재

## 5. 보상수요곡선 vs 통상수요곡선

### 보상수요
- 대체효과만 반영
- 소득효과 제거
- 항상 우하향

### 통상수요
- 대체효과 + 소득효과
- 실제 가격변화에 따른 수요량 변화

정상재:
- 우하향
- 보상수요보다 완만한 방향

열등재:
- 우하향
- 보상수요보다 가파른 방향

기펜재:
- 통상수요 우상향 가능
- 보상수요는 여전히 우하향

## 6. 팔꿈치 직관

보상수요 → 우하향

정상재:
소득효과가 같은 방향으로 추가
→ 통상수요가 더 완만

열등재:
소득효과가 반대 방향으로 작용
→ 통상수요가 더 가파름

기펜재:
소득효과가 대체효과보다 큼
→ 통상수요가 우상향

## 7. Slutsky 그래프 읽기

가격 하락 전 A → 보상된 중간점 B → 최종점 C

A→B = 대체효과
B→C = 소득효과
A→C = 가격효과

시험에서는 그래프를 복잡하게 직접 그리는 것보다 이 구간의 의미와 방향을 읽는 것이 중요.

## 8. 특수관계

### 소득효과=0
가격효과=대체효과
→ 통상수요=보상수요

### 가격효과=0
대체효과+소득효과=0
→ 두 효과가 정확히 상쇄
→ 가격 하락 시 대체효과는 +이므로 소득효과는 -
→ 반드시 열등재

## 9. 문제풀이 알고리즘

가격 변화
→ 대체효과 방향
→ 정상재/열등재
→ 소득효과 방향
→ 두 효과의 절대크기 비교
→ 가격효과
→ 통상수요 방향
→ 보상수요인지 통상수요인지 확인

## 10. 사회보장제도 입문

### 현금보조
현금을 직접 지급.
소비자가 사용처를 선택할 수 있음.

### 현물보조
특정 재화·서비스 또는 바우처 제공.
사용처가 제한될 수 있음.

### 가격보조
특정 재화를 구입할 때 가격을 낮춤.
해당 재화를 구입하는 경우에 혜택 발생.

19강에서는 개념 소개까지 진행되며, 구체적인 그래프 분석은 다음 강의로 연결.

## 11. 시험 포인트

1. 가격효과 = 대체효과 + 소득효과
2. 대체효과는 수요법칙의 예외가 없음
3. 보상수요는 항상 우하향
4. 정상재/열등재/기펜재의 소득효과 방향
5. 기펜재의 정확한 조건
6. 통상수요와 보상수요의 관계
7. 소득효과 0 → 통상수요=보상수요
8. 가격효과 0 → 반드시 열등재
9. Slutsky의 A→B→C 구간 의미
10. 열등재와 기펜재를 구별

## 12. 함정

- 열등재 ≠ 기펜재
- 기펜재 ⊂ 열등재
- 열등재 ≠ 나쁜 재화
- 보상수요 ≠ 대체재
- 보상수요는 항상 우하향
- 기펜재에서 우상향하는 것은 통상수요
- 소득효과 0 → 통상=보상
- 가격효과 0 → 열등재
- 무차별곡선이 무조건 우하향한다고 단정하지 않기
- 무차별곡선은 기수적 효용의 절대적 크기가 아니라 서수적 선호를 표현

## 13. ⭐ 암기 포인트

⭐ 가격효과 = 대체효과 + 소득효과

⭐ 대체효과에는 수요법칙의 예외가 없다.

⭐ 보상수요 = 대체효과만 = 항상 우하향

⭐ 통상수요 = 대체효과 + 소득효과

⭐ 정상재: 대체효과와 소득효과가 같은 방향

⭐ 열등재: 대체효과와 소득효과가 반대 방향

⭐ 기펜재: 열등재 + |소득효과|>|대체효과|

⭐ 소득효과 0 → 통상수요=보상수요

⭐ 가격효과 0 → 대체효과와 소득효과 상쇄 → 열등재
