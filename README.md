# 감정평가사 AI 수험관리 시스템

Repository: `appraiser-study-ai`

## 목적
과목별 학습 기록을 데이터화하여 **진도·취약도·복습·D-Day 스케줄**을 통합 관리하는 개인용 AI 수험관리 시스템을 구축한다.

## 핵심 루프
학습 입력 → 요약/정리 → 질문·오답 기반 취약도 → 복습 → 재평가 → 진도 업데이트 → D-Day 기반 재스케줄링

## 개발 전략
- 1단계: 회계학 모듈을 실제 프로토타입으로 구현
- 2단계: 경제학·지텔프 모듈 확장
- 3단계: 통합 컨트롤타워 및 복습/스케줄 엔진 구축
- 4단계: 대시보드·자동화 고도화

## ChatGPT 프로젝트와의 역할
ChatGPT 감평사 프로젝트: 학습·설계·질문·운영
GitHub: 시스템 설계 문서·코드·데이터 구조·버전 관리

> 과목별 ChatGPT 대화가 모든 데이터를 자동으로 완벽하게 공유한다고 가정하지 않는다. 시스템에서 사용할 핵심 학습 데이터는 구조화하여 별도 데이터 저장소에 축적한다.
