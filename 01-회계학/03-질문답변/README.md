# 03 질문답변

학습 중 발생한 사용자 질문과 AI의 설명을 기록합니다.

## 운영 원칙
- 실제 공부와 질문은 ChatGPT의 `01. 회계학` 채팅에서 진행합니다.
- PDF/이미지/TXT 원본을 ChatGPT에 반복 업로드하는 것을 기본 운영으로 하지 않습니다.
- 질문/응답 원문은 장기적으로 GitHub에 보존하고, 별도의 학습DB로 구조화합니다.
- 원문 질문/응답과 구조화된 학습DB를 분리합니다.
- 질문에서 드러난 오개념, 이해도, 취약개념은 학습DB로 연결합니다.

## 현재 단계
ChatGPT의 다른 채팅 내용을 GitHub가 자동으로 읽어오는 연결은 아직 구현하지 않았습니다.
따라서 1차 버전은:
1. 01. 회계학에서 공부/질문
2. 학습 종료 시 `/메모`로 학습기록 생성
3. 컨트롤타워에서 학습기록을 받아 GitHub에 저장
4. 이후 자동화(API/앱) 검토

## 권장 파일
`YYYY-MM-DD_주제.md`

예: `2026-09-20_유형자산.md`

## 향후 흐름
ChatGPT 공부방 → 질문/응답 추출 → GitHub 저장 → 학습DB 구조화 → 복습엔진 → 취약점/진도 → 스케줄러
