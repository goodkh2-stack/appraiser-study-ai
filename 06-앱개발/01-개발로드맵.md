# 앱 개발 로드맵

## Phase 1 — 회계학 프로토타입
학습 입력 → 데이터 저장 → 진도 표시 → 취약도 표시

## Phase 2 — 복습
복습 예정일 자동 생성 → 복습 결과 기록 → 취약도 조정

## Phase 3 — 스케줄링
시험일 입력 → 단원별 남은 진도 계산 → 주간/일간 계획 생성

## Phase 4 — 통합
경제학·지텔프 추가 → 전체 과목 대시보드 → 통합 컨트롤타워

## Phase 5 — AI
학습내용 요약, 질문 분석, 취약단원 분류, 개인화된 복습 문제 생성, 일정 재조정

## 개발 원칙
처음부터 복잡한 AI Agent를 만들지 않는다. 먼저 데이터 구조와 기본 규칙이 정확하게 작동하는 시스템을 만든 뒤 AI를 단계적으로 연결한다.
