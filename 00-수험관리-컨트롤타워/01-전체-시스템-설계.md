# 전체 수험관리 시스템 설계

## 1. 목표
2027년 감정평가사 1차 시험을 기준으로 과목별 학습 진도와 취약도를 지속적으로 추적하고, 망각 방지와 D-Day 역산을 반영하여 다음 학습 행동을 제시한다.

## 2. 시스템 구조

```
과목별 학습 입력
  ↓
학습 기록/요약
  ↓
질문·오답·복습 결과
  ↓
학습 데이터
  ↓
진도 / 취약도 / 복습 예정일 계산
  ↓
D-Day 기반 스케줄
  ↓
오늘의 학습
  ↓
다시 데이터 축적
```

## 3. 핵심 데이터
- 과목
- 대단원
- 소단원
- 학습일
- 학습시간
- 학습 상태
- 요약
- 질문
- 오답
- 취약도
- 복습 예정일
- 복습 결과
- 시험일

## 4. 중요한 설계 원칙
### 질문은 단순 문의가 아니라 학습 신호다.
질문이 반복되거나 복습에서 오류가 발생하면 해당 단원의 취약도를 높이고 복습 우선순위에 반영한다.

### 스케줄은 고정표가 아니다.
실제 학습량, 진도, 취약도, 복습 누락, 시험일까지 남은 기간에 따라 계속 재계산한다.

### 에빙하우스는 출발점이다.
D+1, D+7, D+30을 기본 복습 후보로 두되, 실제 기억 상태와 취약도에 따라 추가 복습을 배정하는 방향으로 발전시킨다.

## 5. 단계별 개발
1. 회계학 학습 기록 구조
2. 회계학 진도판
3. 질문 기반 취약도
4. 복습 엔진
5. D-Day 스케줄러
6. 통합 컨트롤타워
7. 경제학/지텔프 확장
